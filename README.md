# ITS 레이더

해외 지능형교통체계(ITS) **발주정보와 산업 동향**을 매일 자동으로 모아 한 화면에 띄웁니다.

국제기구·각국 조달 공고를 사람이 매주 직접 뒤지던 일을 자동화했습니다. 발굴·정리·중복제거까지 기계가 하고, **무엇을 쓸지는 사람이 고릅니다.**

## 화면 사용법

- **발주정보 / 기사** 탭으로 나뉩니다
- 기본 화면은 **이번 주에 새로 올라온 것**만 보여줍니다. `신규만` 버튼을 끄면 아직 마감되지 않은 기존 공고까지 나옵니다
- 기간은 `오늘 / 최근 3일 / 이번 주 / 최근 2주 / 전체` 중에서 고릅니다
- `관련도순`은 ITS 밀착도 점수 순입니다. 같은 점수면 마감 임박한 것이 위로 옵니다
- 카드를 누르면 상세가 열리고 버튼이 셋 있습니다
  - **원문 공고 열기** — 발주기관 페이지로 이동
  - **제목 번역** — 파파고로 제목을 넘깁니다
  - **등록문 복사** — 사내 게시판 등록 서식을 클립보드에 담습니다
- 상세의 `관련도`에는 **점수 근거**가 함께 표시됩니다 (`82점 (cpv:34970000, intelligent transport, signalling)`). 왜 이 건이 위에 있는지 화면에서 바로 확인할 수 있습니다
- 주소창에 현재 상태가 남으므로, 특정 화면을 즐겨찾기하거나 링크로 공유할 수 있습니다

## 데이터 소스

| 소스 | 내용 | 인증 |
|---|---|---|
| TED (EU 조달공고) | ITS 관련 CPV 7종의 신규 입찰공고 | 불필요 |
| World Bank | 조달공고 + 조달계획·사업문서(조달예측·기획단계) | 불필요 |

API 키를 쓰지 않습니다. 관리할 자격증명이 없으므로 만료로 멈추는 일도 없습니다.

## 어떻게 돌아가나

```
GitHub Actions (매일 06:00 KST)
  └ collect.py  → 소스 조회 → 중복 제거 → ITS 점수 매김 → data/*.json 커밋
        └ verify.py  → 스키마·중복·점수분포 검사 (실패하면 배포 중단)
                └ GitHub Pages → 화면
```

한 소스가 죽어도 나머지는 수집됩니다. 다만 **전체 결과가 0건이면 실패로 끝냅니다** — 조용히 빈 화면이 뜨는 게 가장 나쁜 고장이라서입니다.

## 검증 이력

만들면서 발견한 문제와 조치입니다.

| 회차 | 발견 | 조치 |
|---|---|---|
| 소스 조사 | 세계은행 조달공고 API만으로는 게시판 등록분의 30%만 커버 | 문서(WDS) API 2종 추가 → 기등록 91건 중 **90건(99%) 재발견** |
| TED 1차 | 현지어 사업명 때문에 ITS 공고가 0점 (체코 과속단속 레이더 등 4건) | CPV 코드로 기본점을 깔고 영어 키워드를 보너스로 합산하는 구조로 교체 |
| TED 2차 | 대형 ITS 사업이 부수 CPV 때문에 잡화로 오인돼 감점 (브르노 ITS 3단계) | 감점 조건을 CPV 15개 이상으로 좁힘 |
| 화면 | 날짜를 UTC로 계산해 한국 오전 9시 이전엔 D-day가 하루 밀림 | 로컬 날짜 기준으로 교체 (타임존 컨텍스트로 재현·확인) |
| SAM.gov | 창 내 215건 중 ITS 핵심어 매칭 **0건** | 편입 보류. 미국 ITS 발주는 주(state) DOT 소관이라 연방 조달망에 오지 않음 |
| World Bank | 마감일 필드를 잘못 잡아 전건 오류 / 제목 필터가 정답 건(케냐 P161305)을 삭제 | 필드 교정 + 섹터 태그가 있는 자료엔 제목 필터 미적용 |

## 로컬에서 실행

```bash
python collect.py     # 수집
python verify.py      # 검증
python -m http.server 8765
```

브라우저에서 `http://localhost:8765`. `index.html`을 직접 열면 브라우저가 JSON 읽기를 막아 빈 화면이 뜹니다.

## 알아둘 것

구글뉴스 RSS·파파고 번역 링크처럼 공식 API가 아닌 경로를 일부 사용합니다. 예고 없이 바뀔 수 있고, 그때는 화면 상단의 `마지막 수집` 날짜가 갱신되지 않는 것으로 드러납니다.
